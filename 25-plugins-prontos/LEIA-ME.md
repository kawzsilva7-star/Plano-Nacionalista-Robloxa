# Plugins prontos (só no PC e no repositório privado)

Cada .zip é um plugin com skills em `skills/<nome>/SKILL.md`. Instalar no Claude: claude.ai → Customize → Plugins → Add → Upload plugin.
Em outros apps (Codex, Gemini CLI etc.): copie as pastas de dentro de `skills/` para a pasta de skills do app.

| Plugin | Quando usar |
|---|---|
| pensar-e-analisar | Conversas e projetos gerais: atacar ideia, prever falha, decidir, ler a fundo |
| essenciais-afiliado | Marketing: revisar texto, oferta, anúncio, imagens |
| conteudo-e-redes | Conteúdo para redes sociais |
| codigo-confiavel | Qualquer projeto de código |
| site-e-seo | Site, Google, página que vende |
| videos-e-audio | Projetos de vídeo e voz |
