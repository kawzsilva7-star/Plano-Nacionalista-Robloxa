# Plano Nacionalista Roblox

Jogo 3D em pixel art para Roblox + biblioteca de skills do dono, separadas por função.

- `roblox/` — design do jogo (`DESIGN.md`), conceito visual (`design_visual.html`) e scripts Luau.
- Pastas `01-` a `26-` — skills por função (`<pasta>/<skill>/SKILL.md`). Lista em `INDICE.md`.
- `CLAUDE.md` — regras para o Claude (quando e como usar as skills, e regras do jogo).
- **Repositório privado.** Ver aviso de licença em `CLAUDE.md`.
