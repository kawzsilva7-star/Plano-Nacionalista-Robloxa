# Pensamento-critico

Skills próprias e de Remotion, em formato de marketplace de plugins do Claude Code.

| Plugin | Skills |
|---|---|
| `avaliacoes` | rodada-de-tubaroes, banca-de-avaliadores |
| `remotion` | video-de-produto e as 13 skills de Remotion |

## Claude Code no seu computador
```
/plugin marketplace add kawzsilva7-star/pensamento-critico
/plugin install avaliacoes@pensamento-critico
/plugin install remotion@pensamento-critico
```
O repositório é privado: o computador precisa estar logado no GitHub (`gh auth login`).
Para puxar as atualizações: `/plugin marketplace update pensamento-critico`.

## claude.ai (chat normal)
Rode `scripts/empacotar.sh` e envie cada `.zip` de `dist/` em Configurações → Capacidades → Skills.

## Prompts salvos
Os arquivos soltos na raiz são prompts prontos para colar no chat.
